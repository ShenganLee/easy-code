# Code of Conduct

easy-code adopts the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/) as its code of conduct. The full text is incorporated by reference and applies to all project spaces, including issues, pull requests, discussions, and private project communication.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainer privately:

- GitHub: [@ShenganLee](https://github.com/ShenganLee) — use the “Report abuse” / private contact options on the profile.
- For security vulnerabilities, use the private reporting channel in [SECURITY.md](SECURITY.md). Do not open a public issue.

Reports are handled confidentially. The maintainer will acknowledge a report within three business days and explain the next steps.

## Enforcement

The maintainer follows the enforcement ladder in Contributor Covenant 3.0: warning, temporary limitation, temporary suspension, and permanent ban. The response focuses on repairing harm and protecting the community.
